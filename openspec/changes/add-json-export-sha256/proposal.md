# JSON 导出内嵌 SHA-256

## 问题

导出的 JSON 没有内容校验值。用户无法核对复制后的文件是否与导出内容一致，写入中断也可能留下半截文件。

## 预期行为

- 导出自动在 JSON 根对象末尾添加 `sha256`，值为 64 位小写十六进制 SHA-256。
- SHA-256 针对没有 `sha256` 字段的原始 UTF-8 JSON 字节计算，包括该 JSON 的闭合括号；避免摘要包含自身。
- 保持现有字段和结构。校验时从原始字节中移除末尾新增的 `sha256` 成员及其前置分隔符，保留原来的末尾闭合括号，重建被哈希的原始字节。不通过重新序列化计算，以免空格、缩进、数字格式改变摘要。
- 先在应用缓存中生成完整基础 JSON，再计算摘要、生成带摘要的完整 JSON，之后写入用户选择的文件。所有流均成功关闭后才报告导出成功。
- 导出失败或取消不得报告成功，清理缓存并尽力删除不完整目标文件；系统提供者拒绝删除时明确提示目标文件可能不完整。
- 文档包含字段说明和 Python 校验示例，并明确重新排版也会改变字节摘要。

## 范围

只修改 sports_monitor 的 JSON 导出、相关失败提示、文档及测试；不修改采集服务或数据库结构。此校验用于检测完整性，不能防止攻击者修改数据后重算摘要。

## 规格变更

扩展 `recording-json-export`：新增摘要计算、校验规则、完整生成后写出以及错误和取消处理要求。

## 验证

覆盖正常导出、空记录、多页记录、中文元数据、编辑后的采样、内容篡改、文件截断、写入失败和协程取消；核对摘要与标准 SHA-256 实现一致。
