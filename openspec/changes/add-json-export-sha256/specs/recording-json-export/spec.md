## ADDED Requirements

### Requirement: 导出 JSON 自动包含内容摘要

系统 SHALL 在成功导出的 JSON 根对象末尾自动添加 `sha256` 字符串，使用 64 位小写十六进制表示。摘要 SHALL 为移除该末尾成员及其前置分隔符后恢复的原始 UTF-8 JSON 字节的 SHA-256，包括原 JSON 闭合括号。实现 SHALL 明确定义可逆的字段追加格式，使校验工具无需重新序列化数据即可恢复参与摘要的字节。

#### Scenario: 成功导出
- **WHEN** 用户导出一条非活动记录
- **THEN** 文件为有效 JSON，保留现有字段，`sha256` 与规定的原始内容字节的 SHA-256 一致

#### Scenario: 内容被修改或文件截断
- **WHEN** 导出文件的数据字节发生变化或文件不完整
- **THEN** 校验工具拒绝该文件，不将缺失摘要或语法错误视为有效校验

### Requirement: 完整生成后写出

系统 SHALL 先在本地缓存生成完整导出内容和摘要，再向目标文件写入，所有输出流成功关闭后方可显示成功。导出失败或协程取消 SHALL 清理临时文件，并尽力删除不完整目标文件；无法删除时 SHALL 提示可能残留不完整文件。数据库记录 SHALL 保持不变。

#### Scenario: 写入失败
- **WHEN** 目标文件写入或关闭失败
- **THEN** 不显示导出成功，清理临时文件并尝试清理目标文件，报告失败

#### Scenario: 导出被取消
- **WHEN** 导出协程被取消
- **THEN** 执行必要清理并传播取消异常，不显示成功
