# Spec Delta

## Purpose

将一条采集记录连同其当前元数据、采样点和单位完整写成可移植的 JSON 文件，供用户保留或在其他工具中分析。

## ADDED Requirements

### Requirement: 导出单次记录为 JSON
系统 SHALL 允许用户为一条非活动记录选择目标文件并导出有效 UTF-8 JSON。JSON SHALL 包含格式版本、记录标识、名称、备注、开始和结束时间、状态、各数据源的可用性、采样点类型、时间、数值和单位；GPS 点 SHALL 包含经纬度和精度。导出 SHALL 使用用户修改后的当前数据，且不改变本地记录。

#### Scenario: 成功导出
- **WHEN** 用户选择一条已停止记录并确认目标文件
- **THEN** 系统写出可解析的 JSON，其中采样点数量和值与本地记录一致

#### Scenario: 取消文件选择
- **WHEN** 用户取消选择目标文件
- **THEN** 系统不生成文件，且本地记录保持不变

#### Scenario: 写入失败
- **WHEN** 目标文件无法写入或写入中断
- **THEN** 系统报告导出失败，不将该操作显示为成功，本地记录保持不变
